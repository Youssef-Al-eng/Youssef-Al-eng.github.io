AI Cable Defect Detection System — Elsewedy Electric

Computer Vision · Real-Time · Industrial AI · Academic project, The Knowledge Hub – Coventry University (2026)

A 5-stage real-time inspection pipeline for cable manufacturing lines: Intel RealSense D435i synchronized RGB+depth capture (60 FPS), custom-trained YOLOv8 detection of three defect classes, SSIM-based frame deduplication, 3D surface analysis, and an operator review workflow. Training used K-fold validation, class-aware augmentation, and anti-bias analysis. Documented results: ~90–95% detection accuracy in project evaluation, ~60% reduction in manual inspection, ~40% faster response.

Python · Ultralytics YOLOv8 · OpenCV · Intel RealSense

FinSight — Banking Document & Chart Q&A Agent

RAG · Vision LLM · FastAPI

A FastAPI backend and web frontend that ingests PDF, DOCX, XLSX/CSV, and TXT; extracts page text and every embedded chart in reading order (PyMuPDF); sends each chart to a Groq vision model that returns exact Category: value data points; indexes three record types with all-MiniLM-L6-v2 embeddings in persistent ChromaDB; keeps multi-turn memory in SQLite; and exports branded Word / PDF / PowerPoint deliverables.

Python · FastAPI · Groq (LLM + vision) · ChromaDB · sentence-transformers · SQLite

AI Physio — Shoulder Clinical Decision Support

Healthcare AI · Multilingual RAG · Docker

A multilingual RAG assistant (English & Egyptian Arabic) covering six shoulder conditions — multilingual sentence-transformer embeddings, FAISS search, and a LangGraph retrieval node — with distance-based confidence scoring, red-flag clinical alerts, three-phase protocols, and condition-specific exercise programs. Shipped with a production Docker setup (multi-stage build, health checks, non-root user).

Python · LangGraph · FAISS · sentence-transformers · Streamlit · Docker

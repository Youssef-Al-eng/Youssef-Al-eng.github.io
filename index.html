03 / Engineering notes

The decisions inside the work.

Short notes on what each experiment makes visible—and where its evidence stops.

01Keep citations at the source blockRetrieval

Multilingual Document Retrieval returns document, page, and block identifiers from pre-parsed content. Keeping the citation attached to the retrieved unit makes the answer easier to inspect; it does not prove broad retrieval quality or replace document parsing and OCR.

02Make refusal a valid routing outcomeReliability

The Risk-Aware Tool Router applies an explicit ceiling to candidate tool risk and can abstain with a reason. This makes the policy observable and testable, while the synthetic scenario assumptions remain a clear limit on what the evaluation can claim.

03Measure exact retention separately from fluencyMemory

The Long-Context Memory Benchmark asks whether exact records survive a compression budget. Its whitespace-token proxy and known fact template are useful for isolating retention mechanics, not for predicting how an LLM summarizes or answers.

04Track what adaptation leaves behindDomain shift

Domain Adapter Arena measures source and target test sets together. The pairing makes source retention visible beside target adaptation in its generated text domains, without implying generalization to licensed corpora or large pretrained models.

05Separate illumination changes from defectsVision

Industrial Anomaly Localization compares raw pixel statistics with per-image normalization after a generated global illumination transform. Pixel maps expose where the detector responds, while synthetic imagery keeps the result at implementation-demonstration scope.

06Preserve workflow state at a committed boundarySystems

Durable Workflow Runtime stores task state and append-only events in SQLite, then resumes without repeating recorded local effects. An arbitrary external side effect cannot share that transaction, so the implementation avoids claiming exactly-once behavior for external services.
